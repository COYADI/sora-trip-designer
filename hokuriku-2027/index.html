北陸立山七日

2027/5/12–5/18 · 松山↔羽田 · 橫濱兩晚、富山四晚。週三到週五上班：週三在台北，週四愛宕後接 K-Arena，週五愛宕後飛富山。週六由立山進、扇澤出，早上趕雪壁，晚上回富山吃飯。週日金澤。

7 天 橫濱 2 晚 富山 4 晚 週三到五上班 K-Arena 立山黑部 金澤

這一週怎麼排

固定的是機票、兩間飯店、週四演唱會、週六縱貫、週日金澤。週三到週五白天留給上班。

上班怎麼接

  • 週三：人在台北。上午上班，下午進松山。晚上才到關內，不到愛宕。
  • 週四：關內 ↔ 愛宕（御成門，MORI タワー）。16:45 前離開，趕 K-Arena。
  • 週五：11:00 退房、行李寄放。愛宕上到 16:00，回關內取行李再去羽田。
  • 週五若會議會拖過 16:30：早上箱子帶去愛宕，下班直接去羽田。

還有哪些「要提醒的小事」

每日表格已經有八欄。這裡是整趟出發前看一次的事。

已進每日表

  • 省錢 — 縱貫買片道、不買 JR Pass
  • 行李／寄放 — 上班日與雪壁日箱子放哪
  • 預約／票務 — 立山 WEB 票、演唱會進場
  • 當日提醒 — 16:00 離班、週六 8:00 纜車與扇澤 15:40
  • 付款 — 電鐵要現金，其餘刷卡
  • 拍照／三餐／設備 — 雪壁、兼六園、關內宵夜

出發前總檢

  • 證件：護照、信用卡兩張。這趟不開車，不用國際駕照。
  • 插頭：日本 A／B 型，台灣插頭多半直接用。
  • App：ANA、Google 地圖、立山黑部 WEB 車票、富山地鐵、轉乘 App、交通系 IC。
  • 通訊：eSIM 或漫遊。山區訊號不穩，票券截圖存手機。
  • 保險：旅遊險。室堂海拔高、天氣會停駛。
  • 上班：週五 16:00 要走，事先跟辦公室說。週四 16:45 前要走出愛宕。

立山黑部

  • 2027 開山日還沒公布。近年約 4 月中旬全線開、11 月底結束。5/15 通常已開山，而且仍是雪壁季節。
  • WEB 票預約的是立山纜車 8:00 出發，前一天下午 3 點前可買（以當年規則為準）。週六雪季仍要早訂。
  • 回富山靠扇澤的長野巴士，再轉新幹線。14:40 與 15:40 都不預約，客滿就下一班。末班 17:00。
  • 風大時大觀峰纜車會停。週五晚看運休。
  • 緊急電話 110／119。

城市與現金

  • 富山地鐵的電車與一般路線巴士不吃 Suica。市內電車可以。機場直行巴士可感應，也收 470 日圓。
  • 刷卡選日圓，不要選折成台幣。
  • 週日近江町有店公休，金澤仍去得成。
  • 演唱會場內規定通常不能錄。

逐日行程

每日表格：省錢、行李、預約、付款、拍照、三餐、設備、當日提醒。

拍照、吃飯、帶什麼

5 月中旬東京與富山大約 4:40 日出、18:35 日落。室堂比平地冷很多，而且人在移動，不為了黃金時刻改交通。

拍照

  • 週三到週五：上班與轉場。只有週四散場、高島水際線的夜景順路。
  • 週六：雪壁趕 9:30 開場。水壩在中午前後，不久留。對雪測光。みくりが池 5 月中不一定有倒影。
  • 週日：兼六園趕上午。東茶屋街陰天更好。
  • 週一：雨晴上午拍立山。下午起霾就收。晚上要早睡。
  • 無人機全程不帶。

三餐

  • 週三深夜與週五到富山：接受便利商店。
  • 週四：愛宕午餐，橫濱站墊一口，散場後關內再吃。
  • 週六：前一晚買飯糰。室堂不坐下吃全餐。
  • 週日：近江町早午餐，晚上富山黑拉麵。
  • 週一午餐在冰見。週二早餐在羽田。

設備

  • 一個機身加手機。廣角與標準變焦蓋得住雪壁、水壩、兼六園。
  • 週六：防滑鞋、防風殼、薄羽絨、手套、帽子、墨鏡、備用電池。行動電源放內袋。
  • 腳架留在富山飯店。雪壁人多又冷，架不起來。
  • 上班那幾天相機不必帶去愛宕。

可以看的預報

  • 立山黑部官網的運休與時刻。
  • 室堂的風速，纜車停駛通常看這個。
  • ANA app 的航廈與班機。
  • 富山地鐵機場線，用 5 月的表，不用冬令表。

現金與刷卡

結論：飯店、山岳 WEB 票、新幹線、超市用信用卡。現金只留口袋。刷卡選日圓。

怎麼付

  • Visa／Mastercard 感應：飯店、WEB 車票、新幹線、羽田。
  • 交通系 IC：京急、JR、市內電車、部分新幹線自由席。
  • 富山地鐵電車與一般巴士：紙券或現金。不要以為 IC 過得了閘。
  • 機場直行巴士：470 日圓，可感應。自動售票少收大鈔，帶千元鈔。

口袋現金

  • 整趟口袋大約 2–3 萬日圓就夠，不必換一大疊。
  • 用途：電鐵紙券、市場、雪壁小賣、萬一 IC 過不了新幹線閘。
  • 在便利商店 ATM 領，不要在機場兌台幣匯率。
  • 回程剩下的零錢在羽田花掉。

不要買的

  • 全國或北陸 JR Pass。長距離新幹線只有週六傍晚從長野回富山一段，加上金澤兩小段，套票划不來。
  • 立山往復票。往復是原路折返用的，縱貫買片道。
  • 只含扇澤↔室堂的早割。那張做不了立山進、扇澤出的全程。
  • 橫濱或東京的觀光一日券。上班那幾天用不到。

天氣與改期

週六若扇澤或立山側停駛，就不要出門。

週六停駛

  • 留在富山市區。週一的雨晴看當天天氣，不提前對調。
  • 週日仍去金澤。
  • 票已買立山進，扇澤側若停駛就下不了山。停駛就留在富山，不要當天改方向。

週五下班拖很晚

  • 箱子若還在關內，就不要硬衝折返。
  • 錯過 19:25 不要假設晚上還有下一班。這頁是以坐上這班、當晚住進富山來排的。
  • 所以備案是早上把箱子帶去愛宕，下班直接去羽田。
